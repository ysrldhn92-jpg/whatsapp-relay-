# מעביר הודעות WhatsApp — אב־טיפוס Android

## מה הפרויקט עושה
- קולט התראות של WhatsApp באמצעות Notification Listener.
- מאפשר לסנן לפי שם קבוצת המקור.
- שומר עד 30 התראות אחרונות בפורמט הכולל את שם הקבוצה ואת הטקסט שהופיע בהתראה.
- מאפשר לשתף ידנית את ההודעה האחרונה דרך תפריט השיתוף של Android.

## מה הוא עדיין לא עושה
- הוא **לא שולח אוטומטית** לקבוצת היעד.
- הוא לא מבטיח חילוץ נפרד ומדויק של שם השולח בכל גרסת WhatsApp.
- התראות מקובצות, תוכן מוסתר, תמונות, סרטונים, הודעות קוליות וקבצים אינם מטופלים באופן מלא.
- עבודה כשהמסך כבוי תלויה בהרשאות, בהגדרות הסוללה ובאופן שבו WhatsApp מציגה התראות.

שליחה אוטומטית לקבוצת WhatsApp אינה נתמכת דרך API רשמי רגיל. אוטומציה באמצעות נגישות/ממשק עלולה להיות לא יציבה, ובדרך כלל אינה יכולה לפעול באופן אמין כשהטלפון נעול.

## בנייה ב-Android Studio
1. פתח Android Studio במחשב.
2. בחר Open ופתח את התיקייה `WhatsAppGroupRelay`.
3. אפשר ל-Gradle להסתנכרן; ייתכן שתידרש התקנת Android SDK 35.
4. חבר טלפון עם USB debugging או בחר Build > Build APK(s).
5. התקן את ה-APK שנוצר בתיקיית `app/build/outputs/apk/debug/`.
6. פתח את האפליקציה, הגדר את שם קבוצת המקור והפעל הרשאת גישה להתראות בהגדרות Android.

## פרטיות
ההודעות נשמרות מקומית בהעדפות האפליקציה. אין בפרויקט שליחה לשרת חיצוני.
